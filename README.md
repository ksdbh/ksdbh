## 👨‍💻 About Me

I'm a software engineer with **4+ years of professional experience**
building backend applications, cloud-native services, and distributed
data processing systems.

My experience spans financial services, enterprise technology,
and federal defense environments.

I particularly enjoy solving problems involving:

- **Backend Engineering** — Python, Java, Spring Boot, REST APIs
- **Distributed Systems** — Kafka, event-driven architecture,
  message processing, and fault tolerance
- **Cloud Infrastructure** — AWS, Terraform, serverless computing
- **Platform Engineering** — CI/CD, Docker, Kubernetes, automation
- **Observability** — CloudWatch, ELK, Prometheus, Grafana
- **Engineering Reliability** — debugging, testing, monitoring,
  and designing for failure

I'm interested in understanding not just how software works,
but **why systems behave the way they do under real-world conditions.**
